# Tax Radar 1.0

Локальный сервис для поиска потенциальных налоговых вычетов по банковской выписке.

## Запуск на macOS
1. Распакуйте ZIP.
2. Откройте папку `tax_radar_service`.
3. Запустите `START_MAC.command`.
   Если macOS не даёт открыть файл — откройте Terminal и выполните `bash START_MAC.command`.
4. При первом запуске сервис установит Python-зависимости и откроет `http://127.0.0.1:8787`.

## Запуск на Windows
Дважды кликните `START_WINDOWS.bat`.

## Что работает
- PDF-выписки Альфа-Банка: реальный разбор операций.
- CSV/XLSX: дата + описание + сумма.
- Поиск кандидатов: медицина, аптеки/лекарства, фитнес, обучение, страхование, благотворительность.
- Все найденные кандидаты включены в расчёт по умолчанию; любую операцию можно снять вручную.
- Ориентир возврата по базовым 13% с консервативным общим социальным лимитом 150 000 ₽ на год.
- Основной результат превращается в 1–2 действия вместо списка транзакций.
- Группировка организаций и готовые тексты запросов.
- Отдельный блок сложных расходов, которые можно разобрать позже.
- Скачивание красивого персонального HTML-пакета.

## Конфиденциальность
Сервис запускается на `127.0.0.1` и обрабатывает выписку локально на вашем компьютере.

## Важно
Tax Radar пока не является официальным налоговым консультантом и не формирует официальную 3-НДФЛ. Расчёт — ориентир; фактический вычет зависит от права на вычет, документов и уплаченного НДФЛ.
