# СделатьВычет 2.3.0

Исправлено:
- KPI «Быстрый путь» больше не обращается к несуществующему `breakdown.easy_refund`.
- Быстрый путь теперь считается одной функцией для основного блока и KPI.
- При ручном снятии/добавлении операций все суммы обновляются согласованно.
- API также возвращает `fast_path` для дальнейшего развития фронтенда.

UI:
- нормальный фирменный SVG-логотип
- дополнительная полировка desktop UI
- существенно улучшенная мобильная адаптация
- sticky CTA на телефоне
- улучшены карточки, состояния загрузки и отчёта

Позиционирование:
**«Найдём ваш налоговый вычет за 5 минут.»**
Сервис помогает найти потенциальные расходы и пройти путь до подачи, но не обещает вернуть деньги сам.
