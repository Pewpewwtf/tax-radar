# Tax Radar GUIDE 1.8.1

Гайд после оплаты упрощён до трёх шагов:

1. Tax Radar показывает, что найдено, и у каких организаций получить документы.
2. Когда документы готовы — подать вычет через Личный кабинет ФНС.
3. Следить за статусом заявления.

Убран отдельный стартовый шаг «проверьте, что ФНС уже знает»:
он создавал слишком много неопределённости до начала действий.

Парсеры, paywall 499 ₽ и merchant enrichment не менялись.
