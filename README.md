# СделатьВычет 2.4.2

Добавлен один публичный social-proof счётчик:

**«Уже нашли вычетов на X ₽»**

Логика:
- увеличивается после каждого успешного анализа;
- используется потенциальный возврат, рассчитанный сервисом;
- хранится только агрегированная сумма;
- merchant names, операции и пользовательские данные в публичную статистику не попадают;
- `/api/public-stats` возвращает только агрегат.

Остальные функции 2.4.1 сохранены.
