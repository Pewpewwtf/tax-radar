# Tax Radar GUIDE 1.8

Главное изменение: после оплаты отчёт теперь содержит персональный 4-шаговый
маршрут до налогового вычета.

1. Проверить сведения, уже поступившие в ФНС.
2. Получить только недостающие справки / попросить организацию передать сведения.
3. Выбрать автоматически понятный маршрут: упрощённый вычет или 3-НДФЛ.
4. Следить за статусом обращения.

Маршрут адаптируется под категории найденных расходов и конкретных поставщиков.
Прогресс чек-листа хранится локально в браузере.

Парсеры и платная воронка версии 1.7 сохранены.
