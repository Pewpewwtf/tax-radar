# Tax Radar 1.4 — Timeweb + оплата

## Что изменилось
- До оплаты `/api/analyze` возвращает только две суммы.
- Детальные транзакции остаются только в памяти backend.
- Цена полного отчёта: 499 ₽.
- После подтверждения оплаты backend открывает `/api/report/{analysis_id}`.
- Сырые PDF/CSV/XLSX не сохраняются.

## Тест без ЮKassa
В Timeweb → Настройки → Переменные добавьте:

PAYMENT_TEST_MODE=1

После нового деплоя кнопка «Получить отчёт» проведёт через тестовый платёж и откроет отчёт без реального списания.

ВАЖНО: перед публичным запуском удалите PAYMENT_TEST_MODE.

## Реальная ЮKassa
Добавьте в Timeweb:

YOOKASSA_SHOP_ID=<идентификатор магазина>
YOOKASSA_SECRET_KEY=<секретный ключ>
PUBLIC_BASE_URL=https://ваш-домен.ru

PAYMENT_TEST_MODE не добавлять.

Цена задаётся в `REPORT_PRICE_RUB = 499`.

## Ограничение MVP
Результат анализа хранится в оперативной памяти приложения 2 часа.
Если контейнер перезапустится между анализом и оплатой, пользователю придётся загрузить выписку заново.
Для production следующий шаг — вынести временные отчёты в Redis/PostgreSQL.
