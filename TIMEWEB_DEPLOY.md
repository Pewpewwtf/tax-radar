# Tax Radar — деплой в Timeweb Cloud

## Вариант 1 — Backend / FastAPI (самый простой)

1. Загрузите содержимое этой папки в GitHub / GitLab / Bitbucket.
2. В Timeweb Cloud откройте **App Platform → Создать → Backend → FastAPI**.
3. Подключите репозиторий и ветку.
4. Версия Python: **3.11**.
5. Команда сборки:
   `pip install --upgrade -r requirements.txt`
6. Команда запуска:
   `uvicorn main:app --host 0.0.0.0 --port 8080`
7. Запустите деплой.
8. После сборки Timeweb выдаст технический публичный домен.

## Вариант 2 — Dockerfile

1. App Platform → Создать → Docker → Dockerfile.
2. Подключите тот же репозиторий.
3. Dockerfile уже лежит в корне.
4. Запустите деплой.

## Проверка после деплоя

- Главная страница: `/`
- Healthcheck: `/health`
- Должен вернуть `{"ok": true, "version": "1.3.0"}`.

## Данные

Текущая версия не использует базу данных.
Загруженная выписка читается в память процесса и не записывается приложением на диск или в БД.
Для production всё равно нужны: политика обработки ПДн, HTTPS, юридическая проверка 152-ФЗ и настройка логирования без чувствительных данных.
